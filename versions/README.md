# Frostfall versions

Earlier builds and related Frostfall games are collected here. [Frostfall Arena Go Go 3D](../README.md) is the main game at the repository root.

| Version | Gameplay |
| --- | --- |
| [Frostfall Arena](arena/README.md) | Original 2D and 3D ice-board strategy game, including Fish Heist. |
| [Frostfall Go Go](go-go-2d/README.md) | 2D penguin auto-battler with draft AI and automatic combat. |
| [Thin Ice](thin-ice/README.md) | 3D skating duel over a lake with breakable ice. |
| [Under the Ice](under-the-ice/README.md) | 3D diving duel and earlier 2D cave modes. |
| [Whiteout](whiteout/README.md) | 3D downhill penguin racing with AI rivals. |
| [Guard Zone](guard-zone/README.md) | Arena variant with defenders and contested landing tiles. |
| [Icebound Docks](icebound-docks/README.md) | Arena variant centered on claiming and connecting docks. |

Open a version’s README to find its launcher, controls, and dependency file. Each version has its own source and runtime assets.
On a fresh setup, install the version’s listed requirements in that folder before launching it.
